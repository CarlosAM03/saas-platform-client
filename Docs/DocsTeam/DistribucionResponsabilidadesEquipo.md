# Distribución de Responsabilidades del Equipo

**Proyecto Integrador — Agosto–Diciembre 2026**

> **Nota de vigencia:** Para Fase 5 esta distribución reemplaza la asignación anterior de ownership. Los documentos normativos del cliente son ADR-005-FlutterFoundation.md y FormularioDecisionesFase5.md.

| Integrante  | Responsabilidad principal          | Responsabilidades secundarias                                            |
| ----------- | ---------------------------------- |------------------------------------------------------------------------- |
| **Carlos**  | Foundation Flutter, arquitectura, integración y DevOps | ApiClient, Auth, routing, DTOs base, configuración, documentación técnica, Prospector Engine, Prospector Service y apoyo transversal |
| **Ángel**   | Backend de plataforma | NestJS, Prisma, PostgreSQL, OpenAPI y endpoints funcionales |
| **André**   | Features Flutter | Pantallas, repositories, providers, widgets y tests de features |
| **Ángeles** | UI/UX y documentación académica | Wireframes, componentes visuales, estados de UI y documentación visual |

## Forma de trabajo

* Cada integrante tendrá ownership de su área principal.
* Carlos coordinará la **integración técnica entre componentes** y apoyará las áreas que lo requieran.
* Carlos priorizará **arquitectura, estructura, configuración, infraestructura, integración y limpieza técnica**, además del desarrollo de sus componentes asignados.
* Los roles no son exclusivos: cualquier integrante puede apoyar en otras áreas o asumir responsabilidades adicionales.
* Las decisiones que afecten a varios componentes deberán coordinarse entre los integrantes involucrados.
* La distribución podrá modificarse conforme avance el proyecto.
